# Сайт-портфолио

Статический сайт без сборки и внешних зависимостей.

## Структура

- `index.html` — разметка главной страницы.
- `css/style.css` — стили и адаптация под разные экраны.
- `js/main.js` — поведение страницы и анимация печати.
- `assets/images/` — изображения и фотографии.
- `assets/fonts/` — локальные шрифты.
- `assets/icons/` — иконки и favicon.
- `files/` — документы для скачивания, например резюме в PDF.

Файлы `.gitkeep` сохраняют пустые папки в Git. При добавлении контента их можно удалить.

## Просмотр

Откройте `index.html` в браузере. Устанавливать зависимости не нужно.

Все ссылки на ресурсы относительные, чтобы сайт работал и в подпапке GitHub Pages.
